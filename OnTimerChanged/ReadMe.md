# My Enigma2 Plugin

This is a plugin for Enigma2 receivers that provides 'Recording hook'.
Every time a timer status changes the script 'timerchanged.sh' is executed.

## Installation

To install this plugin on your Enigma2 receiver, follow these steps:

1. Clone this repository to your local machine:

`git clone https://github.com/MegaV0lt/enigma2-plugin-OnTimerChanged.git`

2. Install the plugin on your Enigma2 receiver:

- Connect your receiver to your computer via SSH or Telnet.
- Copy the folde `OnTimerChanged` directory to the `plugins` directory on your receiver.
- Change the `timerchanged.sh` to your needs.
- Restart your receiver.

That's it! Your plugin should now be installed and ready to use.
